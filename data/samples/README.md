# Raw Sample Documents

이 폴더는 `seed_db.py`가 DB에 시딩하는 기본 코퍼스 원문만 보관한다.

- **여기에 문서를 추가·수정하면 `app/seed_db.py`의 GRADES 등급 시드도 함께 갱신해야 한다.**
  시드가 없는 섹션은 리시딩 시 D4 격리된다(default-deny, `--report`로 점검).
- 시딩 없이 라이브 분류로 시연할 원문은 `data/uploads/`에 둔다 (drag & drop 데모용).
- 문서 안에는 섹션별 D등급을 직접 쓰지 않는다.
- 섹션별 등급, 신뢰도, 엔티티, 검수 상태는 추후 DB에 저장하는 구조로 확장한다.
- 모든 회사명, 인명, 금액, 일정, 토큰, 계약 조건은 데모용 가상 데이터다.
- 파서는 `#` 문서 제목과 `##` 섹션 제목을 기준으로 섹션을 나눌 수 있다.
