# 세이프브레인 제품 소개 (공개 자료)

## 제품 개요
세이프브레인은 가온테크가 개발한 팀 지식 AI 어시스턴트입니다. 팀 노트, 문서함, 챗 데이터를 하나의 지식 베이스로 통합하고, 데이터 보안 등급과 사용자 접근 등급을 실시간으로 판정하는 접근 제어 엔진을 내장하고 있습니다. 하나의 지식봇으로 내부 구성원과 외부 고객을 동시에 서비스할 수 있습니다.

## 주요 기능
섹션 단위 보안 등급 분류, 5단계 접근 모드(차단·마스킹·의미 제한·노출 제한·전체 접근), 감사 로그, 관리자 등급 검수 도구를 제공합니다. 온프레미스와 클라우드 환경 모두 지원합니다.

## 도입 문의
