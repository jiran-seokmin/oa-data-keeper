# 외부 공유 링크 보안 점검 및 사고 대응 보고서

## 점검 배경
보안팀은 DataKeeper 파일럿 환경에서 외부 공유 링크, 관리자 권한 변경, 문서 등급 재분류 로그, 감사 로그 보존 정책을 점검했다. 이번 점검은 정식 고객 온보딩 전에 정책 우회 가능성과 운영 실수를 줄이기 위한 사전 점검이다.

외부 공유 링크는 고객 협력사와 문서를 공유할 때 가장 자주 사용될 기능이다. 외부 사용자는 내부 인증 사용자가 아니므로 공개 정보 외에는 원문 접근이 불가능해야 한다. 또한 링크 만료 시간과 다운로드 가능 여부가 정책과 일치해야 한다.

관리자 권한 변경과 문서 재분류 로그는 감사 가능성을 위해 필수다. 누가 어떤 섹션의 등급을 바꿨는지, 변경 전후 접근 결과가 어떻게 달라졌는지 기록되지 않으면 고객 보안팀에 설명하기 어렵다.

## 발견 사항 요약
테스트 환경에서 외부 공유 링크의 만료 시간이 정책 변경 이후에도 이전 값으로 유지되는 문제가 발견되었다. 신규 링크에는 최신 정책이 적용되었지만, 이미 발급된 일부 링크는 만료 시간이 즉시 재계산되지 않았다. 외부 채널 하드 캡은 정상적으로 적용되어 비공개 원문이 노출되지는 않았다.

또한 관리자 권한 변경 로그에서 변경 사유 필드가 비어 있는 사례가 3건 확인되었다. 변경자와 변경 시각은 기록되었지만, 긴급 변경인지 정기 변경인지 구분할 수 없어 사후 검토가 어렵다. 보안팀은 변경 사유 입력을 필수로 전환할 것을 권고한다.

문서 등급 재분류 로그는 정상적으로 남고 있으나, 재분류 후 영향받는 사용자 수를 바로 확인하는 기능은 없다. 정책 변경 전후로 어떤 페르소나의 접근 결과가 달라지는지 미리 볼 수 있는 시뮬레이션 화면이 필요하다.

## 재현 경로 및 제한 정보
문제 재현은 테스트 테넌트에서 외부 공유 링크를 생성한 뒤, 링크 만료 정책을 14일에서 3일로 변경하는 방식으로 수행했다. 정책 변경 이후 새로 생성한 링크는 3일 만료로 설정되었지만, 기존 링크 2건은 14일 만료를 유지했다.

보안팀은 임시 토큰 값 `tmp_share_7f92_redacted_demo`와 요청 추적 ID `req-20260709-demo-1842`를 확인했다. 이 값들은 실제 운영 토큰은 아니지만, 재현 방식과 결합하면 유사한 테스트를 반복할 수 있으므로 보안팀장 승인 전까지 제한 공유한다.

문제의 핵심은 링크 생성 시점의 정책 사본이 링크 메타데이터에 저장되고, 정책 버전 변경 이벤트가 기존 링크에 전파되지 않는다는 점이다. 접근 시점에 최신 정책을 다시 조회하거나, 정책 버전이 바뀌면 기존 링크의 캐시를 무효화해야 한다.

## 영향도 평가
이번 발견 사항으로 인해 비공개 섹션 원문이 외부 사용자에게 노출된 사례는 확인되지 않았다. 외부 채널 하드 캡은 정상 작동했기 때문에 D1 이상 섹션은 접근 차단으로 처리되었다. 다만 링크 노출 기간이 정책보다 길어지는 것은 고객 계약상 보안 약속 위반으로 해석될 수 있다.

관리자 권한 변경 사유 누락은 즉각적인 데이터 유출은 아니지만, 감사 대응 품질을 낮춘다. 고객이 특정 정책 변경의 배경을 질문했을 때 변경 이력만 있고 사유가 없으면, 운영 통제 수준이 낮아 보일 수 있다.

재분류 영향도 미리보기 부재는 운영 실수 가능성을 높인다. 예를 들어 관리자가 D3 섹션을 D2로 낮추면 C2 사용자에게 원문 접근이 열릴 수 있는데, 현재는 변경 후 실제 화면을 확인해야만 영향을 파악할 수 있다.

## 조치 계획
개발팀은 외부 공유 링크 접근 시 최신 정책 버전을 확인하도록 링크 검증 로직을 수정한다. 기존 링크에 저장된 만료 시간이 정책보다 길 경우, 더 짧은 정책 값을 우선 적용한다. 또한 정책 변경 이벤트가 발생하면 관련 링크 캐시를 즉시 무효화한다.

관리자 권한 변경 화면에는 변경 사유 필드를 필수로 추가한다. 긴급 대응, 정기 점검, 고객 요청, 내부 권한 조정 중 하나를 선택하고 상세 사유를 입력해야 저장할 수 있도록 한다. 기존 사유 누락 건은 보안팀이 담당자에게 확인해 보완 기록을 남긴다.

정책 시뮬레이션은 후속 과제로 등록한다. 변경 전후 접근 결과가 달라지는 섹션 수, 사용자 그룹, 문서 목록을 보여주는 화면을 제공하면 관리자가 재분류 실수를 줄일 수 있다. 해당 기능은 관리자 콘솔 로드맵에 포함한다.
