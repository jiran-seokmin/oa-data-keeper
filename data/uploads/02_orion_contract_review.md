# Project Orion 파트너 계약 검토안

## 외부 공유용 협력 개요
블루웨이브 랩스와 오로라 파트너스는 Project Orion의 공동 프로모션 가능성을 검토하고 있다. 이 소개 문구는 공개 설명용이며 최종 계약 체결을 의미하지 않는다.

## 기본 계약 조건
계약 기간은 2026년 11월 1일부터 1년이며 연간 이용료 초안은 2억 4천만 원이다. 갱신 거절은 종료 60일 전 통지하는 조건으로 사내에서 검토한다.

## 서비스 수준 합의
월간 가용성 목표는 99.5%이고 중대 장애의 최초 응답 목표는 4시간이다. 연락은 양사 운영 책임자 역할을 통해 진행하며 개인 전화번호나 이메일은 이 문서에 기록하지 않는다.

## 독점 우선협상권 특약
오로라 파트너스가 차세대 Orion Edge의 동아시아 유통권을 제안하면 당사는 제3자 제안을 검토하기 전 20영업일 동안 우선 협상한다. 이 내용은 아직 서명되지 않은 계약 조건 초안이다.

## 내부 협상 하한선
법무팀과 경영진만 열람할 협상 하한선은 최소 보장액 16억 5천만 원과 매출 배분율 14%다. 이 기준보다 낮은 제안은 거절하며 상대방과 외부에는 공개하지 않는다.

## 해지 조건 등급 검토 메모
서비스 공급이 30일 넘게 중단되면 즉시 해지할 수 있다는 조항을 검토 중이다. 표준 계약 조건이라는 의견과 향후 협상 전략을 노출한다는 의견이 달라 S 또는 C 중 사용자 확인이 필요하다.

## 내부 승인 경로
계약 초안은 사업 책임자, 법무 책임자, 재무 책임자의 순서로 승인한다. 서명 전 변경 사항은 사내 계약 검토 회의록에 남긴다.

## 문서 고지
이 문서의 회사명, 프로젝트명, 서비스명, 인명, 일정, 계약 조건, 수치와 금액은 모두 동영상 데모를 위한 가상 정보다. 실제 개인정보, 영업비밀, 비밀번호, API 키 또는 접근 자격 증명은 포함하지 않는다.
